# Reuniones

**Bloque:** Gestión del proyecto

Actas, agendas y acuerdos de reuniones, separados por tipo de reunión.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `directorio_y_socios/` | Reuniones de directorio y socios. |
| `equipo_interno/` | Coordinación semanal del equipo. |
| `equipo_desarrollo/` | Planificación de sprints, dailies y retrospectivas. |
| `asesores_expertos/` | Reuniones con fonoaudiólogos, terapeutas y educadores. |
| `familias_y_usuarios/` | Reuniones con familias y usuarios finales. |
| `instituciones_y_alianzas/` | Colegios, escuelas especiales, fundaciones, centros de salud. |
| `inversionistas_y_fondos/` | Inversionistas y ejecutivos de fondos concursables. |
| `plantillas_actas/` | Formato estándar de agenda y acta. |

## Notas

- Nombrar cada acta como `AAAA-MM-DD_tema.ext` para que se ordenen por fecha.
