# Fondos concursables

**Bloque:** Negocio y finanzas

Postulaciones a fondos públicos (y privados) para financiar el proyecto.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `calendario_convocatorias/` | Fondos abiertos, plazos y bases. |
| `corfo/` | Ej.: Semilla Inicia, Semilla Expande, Startup Chile. |
| `anid/` | Ej.: FONDEF IDeA, Startup Ciencia. |
| `senadis/` | Ej.: Fondo Nacional de Proyectos Inclusivos (FONAPI). |
| `sercotec/` | Ej.: Capital Semilla. |
| `gobiernos_regionales/` | Fondos regionales de innovación. |
| `otros_fondos/` | Fondos privados, internacionales y premios. |
| `documentos_base/` | Antecedentes legales, CVs del equipo, cartas de apoyo, plan de negocio. |
| `adjudicados_y_rendiciones/` | Convenios firmados, informes técnicos y rendiciones financieras. |

## Notas

- Los nombres y bases de los fondos cambian cada año: verificar en el sitio de cada institución.
- Dentro de cada institución, crear una carpeta por postulación: `AAAA_nombre_fondo`.
