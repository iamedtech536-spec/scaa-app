# Material educacional

**Bloque:** Contenidos

Material para enseñar a usar la app y para implementar la CAA en casa, aula y terapia.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `guias_familias/` | Guías para familias: uso en casa y modelado. |
| `guias_profesionales/` | Guías para fonoaudiólogos, educadores diferenciales y terapeutas ocupacionales. |
| `manuales_usuario/` | Manual de la app y preguntas frecuentes. |
| `tutoriales_video/` | Videos tutoriales. |
| `capacitaciones_talleres/` | Programas, presentaciones y material de talleres. |
| `actividades_y_planificaciones/` | Actividades para modelar vocabulario en rutinas de casa y aula. |
| `material_imprimible/` | Tableros de comunicación de respaldo en papel y láminas. |
