# Ejemplos de SAAC de alta tecnología

**Bloque:** Investigación

Análisis de sistemas de comunicación aumentativa y alternativa existentes, con Proloquo2Go como referente base.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `proloquo2go/` | Referente base: funciones, navegación, organización del vocabulario, capturas. |
| `apps_comerciales/` | TD Snap, LAMP Words for Life, TouchChat, Avaz, Grid, entre otras. |
| `apps_gratuitas_y_open_source/` | Cboard, AsTeRICS Grid, AraBoard, entre otras. |
| `dispositivos_dedicados/` | Comunicadores dedicados y sistemas de control ocular. |
| `matriz_comparativa/` | Comparación de funciones, precio, idioma, funcionamiento sin internet, accesibilidad. |
| `conclusiones_y_oportunidades/` | Brechas detectadas y oportunidades de diferenciación para Chile. |

## Notas

- Estos sistemas se estudian como referencia. No copiar su vocabulario, símbolos ni diseño visual (ver `05_legal`).
