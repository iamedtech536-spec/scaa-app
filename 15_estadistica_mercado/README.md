# Estadística de mercado

**Bloque:** Negocio y finanzas

Datos y análisis para dimensionar el mercado y la población objetivo.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `fuentes_datos/` | Datos crudos de INE/Censo, Estudio Nacional de la Discapacidad (SENADIS), MINEDUC, MINSAL. |
| `poblacion_objetivo/` | Estimación de niños no verbales o con necesidades complejas de comunicación en Chile. |
| `mercado_chile/` | Colegios, escuelas especiales, centros de terapia y profesionales. |
| `mercado_latam/` | Oportunidades de expansión regional. |
| `competencia_y_precios/` | Participación de mercado y precios de la competencia. |
| `encuestas_mercado/` | Encuestas de disposición a pagar. |
| `informes_y_graficos/` | Informes, gráficos y estimación TAM/SAM/SOM. |

## Notas

- Citar siempre la fuente y la fecha de cada dato.
