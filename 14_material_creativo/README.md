# Material creativo

**Bloque:** Contenidos

Archivos gráficos y audiovisuales originales (archivos fuente y exportados).

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `identidad_marca/` | Logo, paleta de colores, tipografías y manual de marca. |
| `pictogramas_ilustraciones/` | Pictogramas e ilustraciones propias. |
| `iconografia_app/` | Íconos de la interfaz de la app. |
| `audio_y_grabaciones/` | Grabaciones de voz y efectos de sonido. |
| `video_animacion/` | Videos y animaciones. |
| `fotografia/` | Fotografías propias (con autorización de las personas que aparecen). |
| `plantillas_graficas/` | Plantillas para redes sociales, documentos y afiches. |

## Notas

- Los archivos pesados (video, PSD, AI) conviene guardarlos con Git LFS o en una unidad compartida con esta misma estructura.
