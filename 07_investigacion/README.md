# Investigación

**Bloque:** Investigación

Investigación propia del proyecto: trabajo de campo con usuarios y profesionales.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `plan_investigacion/` | Preguntas de investigación, objetivos y metodología. |
| `etica_y_consentimientos/` | Aprobación de comité de ética, consentimiento de padres, asentimiento del niño. |
| `entrevistas_y_encuestas/` | Instrumentos y resultados con familias, fonoaudiólogos, docentes y terapeutas. |
| `observaciones_campo/` | Registros de observación en casa, aula o terapia. |
| `pruebas_usabilidad/` | Pruebas de prototipos con niños y profesionales. |
| `estudio_piloto/` | Diseño y resultados del estudio piloto. |
| `datos_y_analisis/` | Bases de datos anonimizadas y análisis estadístico. |
| `informes_y_publicaciones/` | Informes de resultados, artículos y pósteres. |

## Notas

- **No subir a este repositorio datos que identifiquen a niños o familias** (nombres, RUT, fotos, videos, diagnósticos). Son datos sensibles según la Ley 19.628 y la Ley 21.719. Guardar los datos crudos en un almacenamiento con acceso restringido y subir aquí solo datos anonimizados.
