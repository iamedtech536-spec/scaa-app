# Carta Gantt

**Bloque:** Gestión del proyecto

Planificación temporal del proyecto y su seguimiento.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `gantt_maestro/` | Plan general vigente (una sola versión oficial). |
| `gantt_por_area/` | Gantt detallados por área: desarrollo, investigación, legal, marketing. |
| `gantt_postulaciones_fondos/` | Cartas Gantt exigidas por cada fondo concursable. |
| `hitos_y_entregables/` | Lista de hitos, entregables y fechas comprometidas. |
| `seguimiento_avance/` | Comparación de lo real con lo planificado. |
| `versiones_anteriores/` | Historial de versiones reemplazadas del Gantt. |

## Notas

- Mantener un único archivo vigente en `gantt_maestro`; al actualizarlo, mover la versión anterior a `versiones_anteriores`.
