# Gestión del proyecto

**Bloque:** Gestión del proyecto

Documentos que definen qué es el proyecto, hacia dónde va y cómo se controla.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `vision_y_objetivos/` | Acta de constitución, misión, visión, objetivos y alcance. |
| `modelo_de_negocio/` | Lienzo de modelo de negocio, propuesta de valor y plan de negocio. |
| `gestion_riesgos/` | Matriz de riesgos, responsables y medidas de mitigación. |
| `indicadores_kpi/` | Metas e indicadores para medir el avance y el impacto. |
| `informes_de_avance/` | Reportes de estado periódicos del proyecto. |
| `plantillas/` | Formatos corporativos: actas, informes, oficios, cartas. |
