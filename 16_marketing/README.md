# Marketing

**Bloque:** Negocio y finanzas

Estrategia y ejecución de marketing y comunicación.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `estrategia_y_plan/` | Plan de marketing, segmentación y posicionamiento. |
| `marca_y_mensajes/` | Mensajes clave y tono de comunicación. |
| `redes_sociales/` | Calendario editorial y contenidos. |
| `contenidos_web/` | Textos y SEO del sitio (el código está en `12_aplicativos/pagina_web`). |
| `tiendas_apps/` | Fichas de App Store y Google Play: descripción, capturas, palabras clave. |
| `campanas/` | Campañas de lanzamiento y pagadas. |
| `prensa/` | Comunicados y kit de prensa. |
| `alianzas_y_comunidad/` | Agrupaciones de familias, fundaciones, colegios, embajadores. |
| `metricas/` | Resultados y métricas de marketing. |

## Notas

- Las fuentes de diseño (logo, plantillas) están en `14_material_creativo`.
