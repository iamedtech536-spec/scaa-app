# Legal

Documentos legales propios de la empresa y del producto.

| `constitucion_empresa/` | Escritura, estatutos, inscripción en SII, poderes. |
| `contratos/` | Contratos de trabajo, honorarios, proveedores y desarrollo. |
| `confidencialidad_nda/` | Acuerdos de confidencialidad firmados. |
| `propiedad_intelectual/` | Registro de marca (INAPI), registro de software, cesiones de derechos. |
| `licencias_terceros/` | Licencias de símbolos, voces TTS, librerías y fuentes tipográficas. |
