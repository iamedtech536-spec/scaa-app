# Diseño de producto

**Bloque:** Producto y tecnología

Definición de qué hace la app y cómo se ve, antes y durante el desarrollo.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `requisitos/` | Requisitos funcionales y no funcionales, historias de usuario. |
| `perfiles_usuarios/` | Perfiles de usuario: niño, familia, terapeuta, docente. |
| `vocabulario/` | Listas de vocabulario núcleo y periférico en español de Chile y su organización. |
| `simbolos_pictogramas/` | Sistema de símbolos elegido y criterios de selección. |
| `voces_sintesis_habla/` | Voces TTS, voces infantiles, acento chileno. |
| `ux_ui/` | Wireframes, mockups, prototipos y sistema de diseño. |
| `accesibilidad/` | Tamaño de celdas, contraste, acceso por barrido, criterios WCAG. |
| `roadmap_producto/` | Producto mínimo viable (MVP) y versiones futuras. |

## Notas

- El arte final de los pictogramas va en `14_material_creativo/pictogramas_ilustraciones`; aquí van los criterios y especificaciones.
