# Revisión bibliográfica

**Bloque:** Investigación

Búsqueda, recopilación y síntesis de literatura científica y técnica.

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `protocolo_busqueda/` | Palabras clave, bases consultadas (PubMed, Scopus, SciELO) y diagrama PRISMA. |
| `articulos_cientificos/` | Artículos en PDF. |
| `libros_y_capitulos/` | Libros y capítulos de libros. |
| `tesis/` | Tesis de pregrado y postgrado. |
| `guias_y_documentos_oficiales/` | Documentos de ASHA, ISAAC, MINEDUC, MINSAL, OMS. |
| `fichas_de_lectura/` | Resúmenes y comentarios de cada fuente. |
| `matriz_bibliografica/` | Tabla de síntesis de todas las fuentes revisadas. |
| `gestor_referencias/` | Exportaciones .bib / .ris de Zotero o Mendeley. |

## Notas

- Nombrar los PDF como `AutorAño_titulo_corto.pdf` (ej.: `Light2014_communicative_competence.pdf`).
