# SCAA App

Proyecto de aplicativo de **Sistema de Comunicación Aumentativa y Alternativa (SCAA) de alta
tecnología** para niños no verbales, tomando Proloquo2Go como referente funcional.

Este repositorio organiza toda la información de la empresa y del proyecto: gestión, legal,
investigación, producto, desarrollo, contenidos, negocio y personas.

## Convenciones

- **Nombres de carpetas:** minúsculas, sin tildes, sin `ñ` y sin espacios (se usa `_`). Evita
  errores en Git y entre Windows y macOS.
- **Nombres de archivos:** `AAAA-MM-DD_tema_v01.ext` (ej.: `2026-11-15_reunion_asesores_v01.docx`).
  La fecha al inicio ordena los archivos cronológicamente.
- **Versiones:** subir el número (`v01`, `v02`...) en vez de usar "final", "final2", etc.
- **Carpetas vacías:** Git no guarda carpetas vacías; cada subcarpeta tiene un archivo `.gitkeep`
  que puede eliminarse cuando la carpeta tenga contenido.
- **Carpetas nuevas:** antes de crear una carpeta principal nueva, revisar si el contenido cabe
  en una existente. Si se crea, usar el siguiente número disponible (`20_...`).

## Advertencias

1. **Datos sensibles:** no subir datos que identifiquen a niños, familias o trabajadores
   (nombres, RUT, fotos, videos, diagnósticos, remuneraciones). Son datos sensibles según la
   Ley 19.628 y la Ley 21.719. Guardar los datos crudos en un almacenamiento con acceso
   restringido y subir solo datos anonimizados.
2. **Secretos:** nunca subir claves, contraseñas ni archivos `.env`.
3. **Archivos pesados:** Git no es ideal para PDFs, videos o archivos de diseño grandes. Usar
   Git LFS o una unidad compartida con esta misma estructura.
4. **Propiedad intelectual:** Proloquo2Go y los demás sistemas se estudian como referencia;
   su vocabulario, símbolos y diseño están protegidos y no deben copiarse. Los pictogramas
   ARASAAC tienen licencia no comercial (CC BY-NC-SA). Ver `05_legal/`.
